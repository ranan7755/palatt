## 🌐 How to Fix on Hostinger (`trueproperties.in`)

Look at your Hostinger hPanel Domain portfolio:
It shows: `trueproperties.in 📁 teenpatti`
This means your website folder inside Hostinger is **`public_html/teenpatti/`**.

1. In Hostinger hPanel, click **Websites** (left menu) → click **Manage** next to `trueproperties.in`.
2. Click **File Manager** (under Files).
3. Open `public_html`, then double-click into the **`teenpatti`** folder.
4. Upload all files from this `github-upload` folder:
   - `index.html`
   - `style.css`
   - `script.js`
   - `jackpot-banner-hd.png`
   - `teenpatti-icon-composite.png`
5. Refresh `https://trueproperties.in` in Safari!

> **Pro-Tip**: You can also just upload `standalone.html` and rename it to `index.html` — it contains CSS, JS, and images bundled into a single file so you never have to worry about missing images!

## 🚀 How to Upload to GitHub

1. Open your repository on **[GitHub.com](https://github.com)**.
2. Click **Add file** → **Upload files**.
3. Select and drag all files from this folder directly into GitHub:
   - `index.html`
   - `style.css`
   - `script.js`
   - `jackpot-banner-hd.png`
   - `teenpatti-icon-composite.png`
4. Click **Commit changes**.
5. Go to repository **Settings** → **Pages** → choose `main` branch → click **Save**.
